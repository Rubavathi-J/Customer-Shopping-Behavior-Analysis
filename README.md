# 🛍️ Customer Shopping Behavior Analysis

Data analytics project analyzing **3,900 customer transactions** to understand customer behavior, purchasing patterns, product performance, and subscription trends.

## 🛠️ Tools & Technologies

* Python
* Pandas
* SQL
* Power BI

## 📊 Project Highlights

* Analyzed **3,900 transactions** across **18 columns**
* Cleaned and prepared the dataset using Python
* Handled missing review ratings
* Created customer **age groups**
* Analyzed **revenue by gender**
* Identified high-spending discount users
* Analyzed top-rated products
* Compared Standard vs. Express shipping
* Compared subscribers and non-subscribers
* Identified discount-dependent products
* Segmented customers into **New, Returning, and Loyal**
* Identified top products within each category
* Analyzed repeat purchases and subscription behavior
* Analyzed revenue contribution by age group

## 📈 Power BI Dashboard

Created an interactive Power BI dashboard to visualize:

* Revenue insights
* Customer segmentation
* Product performance
* Shipping preferences
* Subscription impact
* Customer behavior

## 💡 Business Insights

* Identify high-value customers
* Improve customer retention
* Increase subscription adoption
* Optimize discount strategies
* Promote top-performing products
* Develop targeted marketing campaigns

## 🎯 Objective

To transform customer transaction data into **actionable business insights** that support better marketing, customer retention, product positioning, and revenue growth.
